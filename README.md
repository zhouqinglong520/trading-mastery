## 🔑 核心要点

### 情绪周期
- **启动期** → 试错，小仓
- **发酵期** → 加仓，追涨
- **高潮期** → 重仓，持股
- **退潮期** → 减仓，防守
- **冰点期** → 空仓，等待

### 龙头战法
1. **识别龙头** - 市场地位、带动性、稀缺性
2. **介入时机** - 启动、确认、加速
3. **退出策略** - 见顶信号、情绪退潮

### 风险控制
- 单笔止损：-3% ~ -5%
- 单日最大亏损：-5% ~ -10%
- 连续亏损：暂停交易，复盘反思
