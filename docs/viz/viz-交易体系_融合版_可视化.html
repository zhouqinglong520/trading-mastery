第一章

情绪周期判断（超详细操作）

📊 判断标准（量化指标）

  • 短线情绪周期（龙行刺标准）：01结束、02混沌、03确认、04加速、05高潮
  • 中级情绪周期（龙行刺标准）：01开启、02发酵、03高潮、04主跌
  • 情绪周期判断标准（个人复盘标准）：冰点、复苏、高潮、退潮
  • 情绪指标（个人复盘标准）：最高空间板、次高板、天地板、地天板

🔍 具体查看方法（一步步教）

  • 步骤1：查看昨日涨停板数量 → 记录：昨日涨停板数量 = _____ 家
  • 步骤2：查看昨日跌幅榜情况 → 记录：昨日跌幅榜-9%以上个股 = _____ 家
  • 步骤3：查看板块联动性 → 记录：板块联动性 = _____（强/弱/无）
  • 步骤4：查看最高空间板、次高板、天地板、地天板 → 记录：最高空间板 = _____ 板
  • 步骤5：综合判断情绪周期 → 记录：情绪周期 = _____

📖 案例演示

  • 案例1：短线情绪周期 - 混沌期 → 操作策略：低位试错（首板、二板接力）
  • 案例2：中级情绪周期 - 开启期 → 操作策略：指数共振板（首日共振板或先于指数企稳共振板）
  • 案例3：情绪周期 - 高潮期 → 操作策略：龙头格局（第一三周期的时候龙头可以多格局到首阴和反包）

✅ 可执行规则

  • 规则1：短线情绪周期 - 02混沌期 → 低位试错
  • 规则2：中级情绪周期 - 01开启期 → 指数共振板
  • 规则3：情绪周期 - 高潮期 → 龙头格局
第二章

龙头股识别与分类（超详细操作）

📊 判断标准（量化指标）

  • 龙头股定义（龙行刺标准）：某一时期在股票市场的炒作中对同行业板块的其他股票具有影响和号召力的股票
  • 龙头分类（龙行刺标准）：一字龙、换手龙、卡位龙、日内龙、先锋龙、板块龙、分支龙、反包龙、趋势龙、补涨龙
  • 龙头股识别标准（个人复盘标准）：涨幅最大、涨停最早、人气最高

🔍 具体查看方法（一步步教）

  • 步骤1：查看涨幅榜前50名 → 记录：涨幅榜前50名个股 = _____
  • 步骤2：查看板块联动性 → 记录：板块联动性 = _____（强/弱/无）
  • 步骤3：选择龙头股 → 记录：龙头股 = _____（股票代码和名称）
  • 步骤4：查看龙头股的地位 → 记录：龙头股地位 = _____（高/中/低）

📖 案例演示

  • 案例1：选择换手龙（浙江世宝）→ 操作策略：重点关注，等待买入时机
  • 案例2：选择卡位龙（万邦德）→ 操作策略：重点关注，等待买入时机
  • 案例3：选择补涨龙（中交地产）→ 操作策略：重点关注，等待买入时机

✅ 可执行规则

  • 规则1：选择换手龙 → 重点关注
  • 规则2：选择卡位龙 → 重点关注
  • 规则3：选择补涨龙 → 重点关注
第三章

题材理解（超详细操作）

📊 判断标准（量化指标）

  • 题材分类（龙行刺标准）：大题材（政策类、科技类、基因类）、中题材（大题材细分）、小题材（炒冷饭、衍生分支、涨价）
  • 题材周期判断标准（个人复盘标准）：启动期、发酵期、加速期、高潮期、分歧期、反包期、退潮期、冰点期

🔍 具体查看方法（一步步教）

  • 步骤1：查看题材分类 → 记录：题材分类 = _____（大题材/中题材/小题材）
  • 步骤2：查看题材涨幅空间 → 记录：题材涨幅空间 = _____（翻倍起步/大于50%/10-30%）
  • 步骤3：查看题材周期 → 记录：题材周期 = _____（启动期/发酵期/加速期/高潮期/分歧期/反包期/退潮期/冰点期）
  • 步骤4：选择题材 → 记录：选择题材 = _____（题材名称）

📖 案例演示

  • 案例1：大题材 - 基建地产 → 操作策略：龙头格局（浙江建投）
  • 案例2：中题材 - 中药板块 → 操作策略：龙头接力（龙津药业）
  • 案例3：小题材 - 材料涨价 → 操作策略：首板或二板接力

✅ 可执行规则

  • 规则1：选择大题材 → 龙头格局
  • 规则2：选择中题材 → 龙头接力
  • 规则3：选择小题材 → 首板或二板接力
第四章

选股阶段（超详细操作）

📊 判断标准（量化指标）

  • 均线系统：多头排列、均线粘合、突破均线
  • 成交量：放量、缩量、温和放量
  • 突破关键阻力位：突破前期高点、突破平台、突破均线
  • 个股地位：龙头股、跟风股

🔍 具体查看方法（一步步教）

  • 步骤1：查看涨幅榜前50名 → 记录：涨幅榜前50名个股 = _____
  • 步骤2：查看板块联动性 → 记录：板块联动性 = _____（强/弱/无）
  • 步骤3：选择龙头股 → 记录：龙头股 = _____（股票代码和名称）
  • 步骤4：查看均线系统 → 记录：均线系统 = _____（多头排列/空头排列/粘合）
  • 步骤5：查看成交量 → 记录：成交量 = _____（放量/缩量/温和放量）
  • 步骤6：查看是否突破关键阻力位 → 记录：突破关键阻力位 = _____（是/否）

📖 案例演示

  • 案例1：选择强势股 → 操作策略：加入自选股，等待买入时机
  • 案例2：选择龙头股 → 操作策略：重点关注，等待买入时机

✅ 可执行规则

  • 规则1：选择强势股 → 加入自选股
  • 规则2：选择龙头股 → 重点关注
  • 规则3：选择市场热点题材 → 优先配置
  • 规则4：查看均线系统 → 多头排列优先
  • 规则5：查看成交量 → 放量优先
  • 规则6：查看是否突破关键阻力位 → 突破优先
第五章

买入阶段（超详细操作）

📊 判断标准（量化指标）

  • 买在分歧：板块内个股走势分化，部分涨、部分跌
  • 买在恐慌：大盘暴跌、个股暴跌、跌幅榜-9%以上个股 ≥ 15家
  • 买在低位：股价回调到5日线、10日线、20日线附近
  • 买入仓位：冰点期≤10%、复苏期10%-30%、高潮期50%-70%、退潮期≤30%

🔍 具体查看方法（一步步教）

  • 步骤1：查看个股是否有分歧 → 记录：个股分歧 = _____（是/否）
  • 步骤2：查看大盘是否恐慌 → 记录：大盘恐慌 = _____（是/否）
  • 步骤3：查看个股是否回调到低位 → 记录：回调到低位 = _____（是/否）
  • 步骤4：制定买入计划 → 记录：买入价格 = _____元，买入仓位 = _____%，止损线 = _____元
  • 步骤5：执行买入 → 记录：实际买入价格 = _____元，实际买入数量 = _____股

📖 案例演示

  • 案例1：买在分歧 → 操作策略：买入后持有，等待板块再次联动
  • 案例2：买在恐慌 → 操作策略：买入后持有，等待大盘反弹
  • 案例3：买在低位 → 操作策略：买入后持有，等待股价再次上涨

✅ 可执行规则

  • 规则1：买在分歧 → 板块分歧时买入龙头股
  • 规则2：买在恐慌 → 大盘恐慌时买入抗跌的龙头股
  • 规则3：买在低位 → 股价回调到低位时买入龙头股
  • 规则4：制定买入计划 → 明确买入价格、仓位、止损线
