📊 我的交易体系（二十六位游资深度精华版）

第一章：交易哲学与心态

  • 市场永远是对的：市场永远是对的，错的只有自己。在市场面前，永远要谦卑。
  • 情绪周期是根本：掌握情绪周期，比掌握任何技术指标都重要。情绪周期分为：冰点→复苏→高潮→分化→退潮→冰点。
  • 龙头战法是核心：只做龙头，不做跟风。龙头股是市场选择的结果，不是你选择的结果。

第二章：选股体系

  • 只做强势股：只做强势股，不做弱势股。强势股的特征：均线多头排列，成交量放大，突破关键阻力位。
  • 只做龙头：只做龙头，不做跟风。龙头股是市场选择的结果，不是你选择的结果。
  • 紧跟市场热点：紧跟市场热点题材，不做冷门股。热点的判断：涨停板数量，板块联动性，政策支持力度。

第三章：买入时机把握

  • 买在分歧，卖在一致：当市场对一只股票有分歧时买入，当市场一致看好时卖出。
  • 买在恐慌，卖在贪婪：当市场恐慌时买入，当市场贪婪时卖出。
  • 买在低位，卖在高位：买在低位，卖在高位。

第四章：持有与卖出策略

  • 顺势持有：在上升趋势中持有，在下降趋势中卖出。
  • 达到预期收益就卖：达到3-5%收益就卖，不贪心，锁定利润。
  • 走势不符合预期就卖：走势不符合预期立即止损，避免更大亏损。

第五章：仓位管理

  • 顺势加仓：趋势向好时逐步加仓，趋势转弱时逐步减仓。
  • 逆势减仓：趋势转弱时逐步减仓，不要逆势加仓。
  • 严格控制：单只个股不超过5成仓，总仓位不超过8成仓。

第六章：风险控制

  • 严格止损：跌破止损线（-3%到-5%）立即止损，保护本金。
  • 保护本金：本金比赚钱更重要，风险控制是交易的生命线。
  • 控制回撤：控制回撤比追求暴利更重要，回撤控制好了，复利自然就来了。

第七章：情绪周期判断

  • 冰点：市场情绪极度低迷，涨停板数量少于10只，跌幅榜上躺着众多跌停或大跌个股。操作：空仓观望，等待复苏。
  • 复苏：市场情绪开始回暖，涨停板数量增加到20-30只，板块开始有联动性。操作：小仓位试错，寻找龙头。
  • 高潮：市场情绪极度高涨，涨停板数量超过50只，板块全线飘红。操作：满仓操作，但随时准备撤退。

第八章：龙头战法

  • 龙头股特征：涨幅靠前，涨停最早，封单最坚决。
  • 龙头战法操作方法：识别龙头，买入龙头，持有龙头。
  • 龙头战法注意事项：只做龙头，不做跟风；龙头股是市场选择的结果，不是你选择的结果。

第九章：超短百科全书

  • 超短百科全书内容：K线形态、成交量研究、成本均线、筹码理论、分时研究。
  • 超短百科全书使用方法：建立自己的超短百科全书体系，实践三种模式，每天复盘。
  • 超短百科全书注意事项：K线形态、成交量研究、成本均线、筹码理论、分时研究。

第十章：模式转换心法

  • 为什么要转换模式？：市场环境变化，资金规模变化，个人能力提高。
  • 如何从低吸转换到追涨打板？：学习新知识，小资金试错，逐步形成新系统。
  • 模式转换的注意事项：不要急于求成，不要固步自封，不要模式混乱。

第十一章：控制回撤体系

  • 为什么要控制回撤？：回撤50%，需要涨100%才能回本；回撤越大，回本难度越大；控制回撤是稳定盈利的关键。
  • 如何控制回撤？：仓位管理，止损设置，模式选择。
  • 控制回撤的注意事项：不要逆势加仓，不要不止损，不要频繁交易。

第十二章：指数气氛判断

  • 上证下跌，创业板大跌，是28齐跌，禁止开仓：上证下跌，创业板大跌，是28齐跌，禁止开仓。
  • 上证大涨，创业板大涨，是28齐涨，满仓做多：上证大涨，创业板大涨，是28齐涨，满仓做多。
  • 上证大涨，创业板大跌，是28分化，小仓位做：上证大涨，创业板大跌，是28分化，小仓位做。

第十三章：实战案例分析

  • 案例一：低吸操作：某股短期跌幅较大，分时图出现急跌。操作过程：观察→低吸→持有→卖出。
  • 案例二：追涨操作：某题材成为市场热点，龙头股走势强劲。操作过程：识别→选股→买入→卖出。
  • 案例三：打板操作：某股快速上板，市场氛围好。操作过程：识别→选股→买入→卖出。

第十四章：学习路径与计划

  • 学习路径：第一阶段（1-2个月）→第二阶段（3-6个月）→第三阶段（6-12个月）。
  • 学习计划：每日学习，每周学习，每月学习。
  • 学习注意事项：不要急于求成，不要固步自封，不要模式混乱。

第十五章：核心要点总结

  • 交易哲学：市场永远是对的，情绪周期是根本，龙头战法是核心。
  • 选股体系：只做强势股，只做龙头，紧跟市场热点。
  • 买入时机：买在分歧，卖在一致；买在恐慌，卖在贪婪；买在低位，卖在高位。
