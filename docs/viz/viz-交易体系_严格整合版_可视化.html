交易哲学与核心理念

市场本质观 + 顶级交易者必备的特质

✅ 1.1 市场本质观

规则1：市场永远是对的
  • 当市场走势与预期不符时，首先承认自己错了
  • 不要对抗市场，不要幻想市场会按照你的想法走
  • 亏损时立即止损，不要抱有任何幻想
规则2：概率思维，而非确定性思维
  • 每笔交易都是概率游戏，没有100%确定的交易
  • 追求高胜率+高赔率的交易机会
  • 接受亏损是交易的一部分
规则3：情绪周期是盈利的核心
  • 赚钱效应好时，大胆做多
  • 亏钱效应明显时，空仓观望
  • 情绪周期比技术指标更重要

✅ 1.2 顶级交易者必备的特质（来自0828顶级交易者必备的特质-.pdf）

特质1：极强的自律性
  • 严格执行交易计划，不随意更改
  • 严格执行止损，不抱幻想
  • 严格执行仓位管理，不重仓赌博
特质2：极强的耐心
  • 等待高胜率机会，不频繁交易
  • 持仓时耐心持有，不急于止盈
  • 空仓时耐心等待，不急于进场
特质3：极强的执行力
  • 按照交易计划执行，不犹豫
  • 按照止损计划执行，不拖延
  • 按照仓位管理执行，不冲动

情绪周期判断体系

5个阶段 + 3个工具 + 4个细节规则

✅ 2.1 情绪周期阶段划分

阶段1：冰点（亏钱效应极致）
  • 连扳高度压缩到2板或以下
  • 空间板断板或无空间板
  • 昨日涨停今日跌停现象出现
  • 炸板率>40%
  • 红盘家数<1000家
阶段2：修复（亏钱效应减弱）
  • 连扳高度开始回升（3板或以上）
  • 炸板率下降到20-30%
  • 红盘家数回升到1500家以上
  • 出现反包板或地天板
阶段3：发酵（赚钱效应转好）
  • 连扳高度突破到4板或以上
  • 出现空间板（打破近期高度压制）
  • 炸板率<20%
  • 红盘家数>2000家
  • 龙头股开始形成

✅ 2.2 情绪周期判断工具

工具1：大盘情绪监控表
  • 每天收盘后填写日期、红盘、绿盘、涨停、跌停、炸板率、首板、二板、三板、三板以上、连板数量、1进2、2进3、3进多、情绪周期
  • 情绪周期="强"：涨停>80家，跌停<10家，炸板率<20%
  • 情绪周期="弱"：涨停<50家，跌停>20家，炸板率>30%
工具2：中级周期监控表
  • 中级周期启动期 → 大胆做多
  • 中级周期发酵期 → 重仓龙头
  • 中级周期高潮期 → 持仓不动
  • 中级周期衰退期 → 止盈离场
  • 中级周期冰点期 → 空仓观望

✅ 2.3 情绪周期判断的细节规则（来自0927错题集.txt）

规则1：判断冰点的大小
  • 如果冰点前两天才高潮，那么这个冰点只是小冰点
  • 小冰点之后的行情只是反抽，并不是反转
  • 冰点极致才会出拐点，拐点才会出龙头
规则2：判断次日情绪
  • 连续跌两天对隔日有情绪弱变强的预期
  • 但是第三天是未知的，可能拉，可能震荡
  • 如果不涨，那么昨天的超盘资金就会变为砸盘资金

复盘体系（严格整合个人复盘模板）

每日复盘流程 + 每周复盘流程 + 每月复盘流程 + 复盘后要做的事

✅ 9.1 每日复盘流程（来自如何复盘-游资训练营（第一版）.pptx 和 0727复盘流程.xlsx）

流程1：盘后复盘（15:00-16:00）
  • 看涨停板数据：涨停板数量、跌停板数量、炸板率、连扳高度、空间板
  • 看板块效应：主流题材、板块内涨停板数量、板块效应强度
  • 看龙头股：空间板、板块龙头、龙头股状态
  • 看情绪周期：当前情绪周期位置、次日情绪预期
  • 填写大盘情绪监控表
流程2：盘后选股（16:00-17:00）
  • 选出次日可能操作的股票：主流题材、龙头股、补涨股、加入自选股
  • 分析次日操作策略：操作策略、仓位、止损价、止盈价
流程3：盘后学习（17:00-18:00）
  • 学习游资心法：今日学习、心得
  • 分析自己的交易记录：今日交易、盈利/亏损、原因

✅ 9.2 每周复盘流程（来自1010 1 交易系统1010.pptx）

流程1：周复盘（每周五15:00-17:00）
  • 回顾本周交易记录：本周交易次数、盈利次数、亏损次数、胜率、总盈利/总亏损
  • 分析本周交易：盈利交易分析、亏损交易分析、总结盈利模式和亏损原因
  • 制定下周交易计划：下周关注题材、下周关注龙头股、下周操作策略

✅ 9.3 每月复盘流程（来自1010 1 交易系统1010.pptx）

流程1：月复盘（每月最后一个交易日15:00-18:00）
  • 回顾本月交易记录：本月交易次数、盈利次数、亏损次数、胜率、总盈利/总亏损
  • 分析本月交易：盈利交易分析、亏损交易分析、总结盈利模式和亏损原因
  • 制定下月交易计划：下月关注题材、下月关注龙头股、下月操作策略

✅ 9.4 复盘后要做的事（来自如何复盘-游资训练营（第一版）.pptx）

事项1：更新交易日志
  • 记录每笔交易的细节
  • 记录盈利/亏损原因
  • 记录情绪状态
事项2：更新错题集
  • 记录每笔亏损交易的原因
  • 记录错误操作
  • 避免重复犯错
事项3：更新自选股池
  • 加入新题材龙头股
  • 剔除旧题材跟风股

交易八大关

来自1011 交易八大关.txt

✅ 14.1 八大关详解

第一关：止损关
  • 交易者要取得成功至少需要过这一关
  • 学会止损后，保护本金
  • 操作细节：每笔交易都必须设置止损
第二关：顺势关
  • 学会止损后，还要学会顺势交易
  • 不顺势交易会慢性失血
  • 操作细节：按照行情大方向做单
第三关：轻仓关
  • 学会了截断亏损让利润奔跑，但要轻仓交易
  • 重仓会猝死
  • 操作细节：轻仓交易，不再急于求成
第四关：择时关
  • 轻仓操作下，赚钱速度慢
  • 但不要每时每刻都有交易做
  • 操作细节：一年中只需要抓住那几次有限的行情即可
第五关：系统关
  • 把交易理念转化为具体的操作规则
  • 构建自己的交易系统
  • 操作细节：交易系统必须是初始资金、入场、止损、止盈、加减仓五位一体的系统
第六关：自信关
  • 交易系统构建成功了，但严格按照信号操作后，却碰到了连续亏五六笔的情况
  • 不要怀疑自己的系统
  • 操作细节：连输连错不过是坏的游程在起作用
第七关：重复关
  • 交易者明白了亏损是交易的必然组成部分
  • 不要去设计测试其他系统
  • 操作细节：专心按照既有系统信号操作，不断重复盈利模式
第八关：自在关
  • 交易者防止每个错误的方法都已规则化
  • 每次交易都能做到严格执行规则
  • 操作细节：修炼定力，不为外界信息所扰

错题集与心得

来自0927错题集.txt - 22条交易心得和规则

✅ 15.1 错题集（22条）

  • 1. 指数周期是用来做情绪参考，用来避免炸板潮的
  • 2. 学会判断冰点的大小，如果冰点前两天才高潮，那么这个冰点只是小冰点
  • 3. 低吸要分两笔操作，今日分歧买点和次日反包买点
  • 4. 前排再次超预期的时候应该直接上前排，不应该去后排做补涨
  • 5. 做股票想要大成，不是盯着股票本身，而是整个股票市场的多空格局
  • 6. 人气龙头启动于指数下跌末期，强化于指数上涨中期
  • 7. 控制自己的情绪交易，直到你看清了市场情绪，否则绝对不开仓
  • 8. 龙头启动于几板不重要，重要的是当时的情绪环境龙头有没有起到重要
  • 9. 永不止损，永不止盈（操作是操作，盈亏交给市场）
  • 10. 龙头的定义并不在于板好板烂，而在于本身所具有的特性，有市场炒作的空间
  • 11. 但凡有亏钱效应的板块，都要回避，这是进攻节奏不完美的体现
  • 12. 模仿的个股要等次日超预期才是买点
  • 13. 指数高潮当天不打板、不追高，最多玩玩强势人气股的低吸
  • 14. 龙头三板的时候打补涨首板是百分百有套利空间的
  • 15. 中级周期也不是每一个阶段都要经历的
  • 16. 出现空间突破的时候就是赚钱效应非常好的时候
  • 17. 市场情绪监控表是对隔日情绪做一个判断
  • 18. 市场迷茫的时候，指数下跌的时候才有机会
  • 19. 当个股连续缩量加速高位板的时候，就是风险来临的时候
  • 20. 市场非常高潮的时候要么持仓，要么空仓，不要追涨
  • 21. 判断次日情绪为震荡，且接力不行的时候，个股缩量高开直接砸
  • 22. 次日对超空间的博弈只用三成仓位去做
