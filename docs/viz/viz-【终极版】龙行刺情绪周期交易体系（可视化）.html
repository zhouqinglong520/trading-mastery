2.1 龙头股类型

类型 定义 买点 卖点
空间龙 市场上连板高度最高的个股 爆量分歧日低吸 跌破5日线
补涨龙 主线退潮后低位崛起 首板/二板弱转强 高度达7板或板块分化
反包龙 二波突破 0.618支撑位首板打板 二次断板无承接
切换龙 新题材卡位 板块首次联动首板 板块持续性证伪
日内龙 市场上首先涨停的个股 每个板块在某一个阶段，都有一些资金尝试发动行情 单日试错为主
先手龙 突然的利好，导致资金认可，提前涨停启动 比板块其它个股领先身位 率先启动，相对抛压更小
板块龙 板块中最先涨停连板身位最高的个股 两个都符合的才叫龙，不要求高度 板块内最先涨停
中军 市值超过100亿，交易额在20亿以上的个股 一般是大资金的战场 容量大，走势稳

手法1：连板接力

项目 内容
买点 1. 分歧先手（三成）
2. 高开竞价/打板（五成）
仓位 1. 分歧先手：三成
2. 高开竞价/打板：五成
逻辑 1. 分歧先手：题材经过爆量分歧，提前预判该题材继续走远，有想象空间，低吸三成
2. 高开竞价/打板：题材经过爆量分歧，次日弱转强带动板块发酵，满仓打板

2. 高开竞价/打板：次日非加速-平开/低开

📝 查看方法：

步骤3：执行买入（打开交易软件，输入股票代码，输入买入价格和数量，确认买入）

步骤4：记录交易（打开"交易记录表"，记录日期、股票名称、买点、仓位、逻辑、止损点）

📈 4. 持有阶段：龙头格局与切换

4.1 龙头格局条件

✅ 可以格局的条件：

1. 中级周期第一阶段（开启） - 龙头可以多格局到首阴和反包

2. 中级周期第三阶段（高潮） - 龙头可以多格局到首阴和反包

3. 龙头首次阴线 - 可以低吸，等待反包

4. 龙头反包 - 可以格局到二波结束，跌破5日线再卖

4.2 切换条件

🔄 需要切换的条件：

1. 龙头高潮意味着次日开始分歧 - 可以注意低位板块，做切换

2. 板块全面发酵，板块内连板增多 - 这个时候跟风都是卖点，可以切换低位新题材

3. 有新的板块或题材成为新的主流 - 这个属于板块挤压效应，在熊市中，资金有限，多线作战，必然导致资金分流，后继无力，可以切换到新主流

💸 5. 卖出阶段：卖点判断与执行

5.1 空间龙头卖点

📝 卖点条件：

1. 在赚钱效应回暖和赚钱效应高潮期一直拿住

2. 龙头确认断板 - 卖出2/3

3. 留1/3走完反包破5日线再卖

5.2 分支套利卖点

📝 卖点条件：

次日有利润就走

5.3 分支龙头卖点

📝 卖点条件：

1. 当天炸板

2. 情绪超预期：对情绪次日判断分歧，但最高或者次高依然是一字走加速，此时分支龙如果平开或者低开快速杀跌的话，是会吃到情绪溢价的，如果持仓，就不着急卖

🛡️ 7. 风险控制：止损与防守

7.1 止损规则

📝 止损条件：

1. 个股跌破关键支撑 - 如5日线，立即离场

2. 板块退潮 - 跌停≥5家，立即离场

3. 龙头断板 - 卖出2/3，留1/3走完反包破5日线再卖

4. 次日非弱转强 - 低开无承接，立即离场

7.2 空仓原则

✅ 必须空仓的条件：

1. 中级周期第四阶段（主跌）+ 短线混沌期 - 强制空仓3日以上

2. 双重叠加风险 - 当短线周期的混沌阶段 + 中级周期的发酵/主跌阶段，立即空仓！

3. 连板高度压至4板以下 - 空仓

4. 跌停家数＞20家 - 空仓

🧠 9. 心态管理：交易心理训练

9.1 心态管理原则

✅ 心态管理原则：

1. 赚钱的时候明白是市场行情给的

2. 亏钱：控制好仓位、模式内的操作可以接受、不能使操作变形

3. 积极的心态足以让你做成任何事情

4. 交易之道在人心，人心之道生情绪。掌控自己，才能不被市场掌控，否则会有踩不完的坑

9.2 训练方式

💪 训练方式：

1. 执行计划 - 计划交易，交易计划，多做静态交易，按照计划执行

3. 没有踏空 - 没有踏空之说，错过了等待下一次
