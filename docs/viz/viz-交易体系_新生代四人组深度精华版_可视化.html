📝 可执行规则示例

示例1：符合条件清单（第1章）

每次操作前，必须回答以下问题（✅ 必须全部符合）：
[ ] 市场永远是对的？
[ ] 是否是主流题材？
[ ] 是否是龙头股？
[ ] 是否符合"人气带来的流动性溢价"？
[ ] 是否有"确定性"？
[ ] 是否在熊市中做到稳定盈利？

使用方法：每次操作前，逐项检查，全部符合才操作，否则一律不做。

示例2：选股打分表（第2章）

题材（10分）：是否是主流题材？是否是新题材？
形态（10分）：是否突破？是否缩量？是否平台整理？
人气（10分）：是否人气所向？是否市场焦点？
小盘（10分）：流通市值是否≤100亿？
低价（10分）：股价是否≤20元？
龙头（10分）：是否是龙头股？
板块（10分）：是否有板块联动？
情绪（10分）：是否符合情绪周期的主升阶段？
确定性（10分）：是否有"确定性"？
主流（10分）：是否符合"只做主流题材"？

使用方法：总分≥40分才考虑买入。

示例3：卖出条件模板（第4章）

1. 达到预期收益（如：+10%）就卖
2. 跌破5日线就卖
3. 板块退潮就卖
4. 龙头炸板就卖
5. 不及预期（如：竞价低开）就卖
6. 不参与任何性质整理（ASKING）
7. 持股时间管理（小鳄鱼）：
   - 基本是隔日交易，持股1-2天
   - 行情好时，可能适当增长持股时间
   - 行情不好时，必须隔日交易
   - 根据具体盘面灵活调整

使用方法：买入前先想好"卖出条件"（触发器），达到条件就卖，不要犹豫。

示例4：分仓操作SOP（第5章）

首次买入：≤50%仓位
确认是龙头后：可以加到≤70%仓位
Never 满仓！最多≤70%仓位

每日最大损失控制：
1. 每笔交易止损≤3%
2. 每天总止损≤5%
3. 如果当天止损达到5%，立即停止交易，反思错误

使用方法：严格按SOP执行，不要临时改变计划。
