## 第一章：市场情绪判断（超详细操作）

### 📊 判断标准（量化指标）

#### 1. 昨日涨停板数量
- **冰点**：昨日涨停板数量 ≤ 10家`
- **复苏**：昨日涨停板数量 11-30家`
- **高潮**：昨日涨停板数量 ≥ 30家`
- **极度高潮**：昨日涨停板数量 ≥ 50家`

#### 2. 昨日跌幅榜情况`
- **正常**：跌幅榜-9%以上个股 ≤ 5家`
- **恐慌**：跌幅榜-9%以上个股 6-15家`
- **极度恐慌**：跌幅榜-9%以上个股 ≥ 15家`

#### 3. 板块联动性`
- **强联动**：同一板块涨停个股 ≥ 3家`
- **弱联动**：同一板块涨停个股 1-2家`
- **无联动**：无板块效应`

#### 4. 市场情绪综合判断`
- **冰点期**：昨日涨停板 ≤ 10家 + 跌幅榜 ≥ 6家`
- **复苏期**：昨日涨停板 11-30家 + 跌幅榜 ≤ 5家`
- **高潮期**：昨日涨停板 ≥ 30家 + 板块强联动`
- **退潮期**：昨日涨停板急剧减少 + 跌幅榜增加`

### 📊 判断标准（量化指标）`

#### 1. 上证指数走势`
- **上涨**：涨幅 ≥ +0.5%`
- **下跌**：跌幅 ≥ -0.5%`
- **震荡**：涨跌幅在 -0.5% ~ +0.5% 之间`

#### 2. 创业板指数走势`
- **上涨**：涨幅 ≥ +0.5%`
- **下跌**：跌幅 ≥ -0.5%`
- **震荡**：涨跌幅在 -0.5% ~ +0.5% 之间`

#### 3. 上证指数与创业板指数的关系`
- **28齐跌**：上证指数跌幅 ≥ -0.5% + 创业板指数跌幅 ≥ -0.5%`
- **28齐涨**：上证指数涨幅 ≥ +0.5% + 创业板指数涨幅 ≥ +0.5%`
- **28分化**：上证指数与创业板指数走势相反`

## 第三章：选股阶段（超详细操作）`

### 📊 判断标准（量化指标）`

#### 1. 均线系统`
- **多头排列**：5日线 > 10日线 > 20日线 > 60日线`
- **均线粘合**：5日线、10日线、20日线相差 ≤ 5%`
- **突破均线**：股价站上5日线、10日线、20日线`

#### 2. 成交量`
- **放量**：成交量 ≥ 5日均量的1.5倍`
- **缩量**：成交量 ≤ 5日均量的0.7倍`
- **温和放量**：成交量 = 5日均量的1.2-1.5倍`

#### 3. 突破关键阻力位`
- **突破前期高点**：股价创近期新高`
- **突破平台**：股价突破横盘震荡区间`
- **突破均线**：股价站上关键均线`

#### 4. 个股地位`
- **龙头股**：板块内涨幅最大、涨停最早、人气最高`
- **跟风股**：板块内涨幅较小、涨停较晚、人气较低`
